# 🎓 University Placement Portal

A full-stack **University Placement Portal** built using the **MERN stack** that connects students and recruiters through a centralized job and application system.

---

## 🚀 Features

* 🔐 JWT-based Authentication (Student & Company)
* 👨‍🎓 Student Dashboard (View Jobs, Apply, Track Applications)
* 🏢 Company Module (Post Jobs, Manage Listings)
* 📄 Application Tracking System
* 🔒 Protected Routes & Role-based Access
* 📱 Responsive UI with modern glassmorphism design

---

## 🛠️ Tech Stack

* **Frontend:** React (Create React App), Axios
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Auth:** JWT, bcrypt

---

## 📁 Project Structure

```
client/   → React frontend  
server/   → Node + Express backend  
```

---

## ⚙️ Setup

```bash
git clone https://github.com/your-username/university-placement-portal.git
cd university-placement-portal
```

### Install dependencies

```bash
cd server && npm install
cd ../client && npm install
```

### Run project

```bash
# backend
cd server
npm run dev

# frontend
cd client
npm start
```
